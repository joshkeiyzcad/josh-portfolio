JOSH KEIYZ CAD - PERSONAL PORTFOLIO
===================================

FILES
- index.html : page content
- styles.css : responsive dark theme and layout
- app.js     : mobile navigation, copy-email interaction, current year

OPEN ON WINDOWS
1. Extract the ZIP file if you downloaded the ZIP.
2. Open the extracted folder.
3. Double-click index.html. It should open in your default browser.
4. You do not need Node.js, npm, PowerShell, or an internet connection to run this static site.

PERSONALIZE YOUR CONTACT EMAIL
1. Right-click index.html and choose Open with > Notepad (or open it in VS Code).
2. Search for: your.email@example.com
3. Replace BOTH occurrences with your real email address.
4. Save the file and refresh the browser.

PUBLISH ONLINE
This is a static website and can be hosted by services such as GitHub Pages or Netlify.
Upload index.html, styles.css, and app.js together, keeping their filenames and folder relationship.
Before publishing, replace the placeholder email and check the website on desktop and mobile.

PROJECT STATUS
The equipment-rental marketplace is presented as a portfolio project prototype. The preview graphic is an illustrative concept, not a live embedded version of the separate marketplace. Do not claim backend, permanent storage, or payments unless those are implemented separately.
